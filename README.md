# Super Taikyu Live Viewer (Car 104)

スーパー耐久レースの**Car No.104 のラップ数をリアルタイムで表示**するWebアプリです。

---

## 準備するもの

以下の2つをあらかじめインストールしておいてください。

- [Git](https://git-scm.com/) — ソースコードをダウンロードするツール
- [Node.js](https://nodejs.org/) — サーバーを動かすツール（LTS版を推奨）

---

## セットアップ手順

### 1. このリポジトリをダウンロード（clone）

「リポジトリ」とは、このアプリのファイル一式がまとまった場所のことです。  
以下のコマンドを実行すると、自分のパソコンにコピーされます。

```bash
git clone https://github.com/Ukyo-Nawano/super-taikyu-live.git
```

### 2. フォルダに移動

```bash
cd super-taikyu-live
```

### 3. 必要なパッケージをインストール

アプリが動くために必要なファイルをまとめてダウンロードします。

```bash
npm install
```

### 4. サーバーを起動

```bash
node server.js
```

### 5. ブラウザで開く

以下のURLをブラウザのアドレスバーに入力してください。

```
http://localhost:3001
```

---

## 仕組み

```
ブラウザ
  ↓ 1秒ごとに確認
更新があった？
  ↓ あれば
最新データを取得して画面に表示
```

---

## 表示される情報

| 項目 | 内容 |
|------|------|
| LAPS | 現在の周回数 |
| Last Lap | 直前のラップタイム |
| Best Lap | 最速ラップタイム |
| PIT IN | ピットに入っているとき表示 |
